# Minecraft Bedrock GDK Launcher (BETA)

Minecraft Bedrock GDK Launcher used to run Minecraft Windows edition on Mac using Wine and D3DMetal, built using WineForge and GPTK 4.
You have to own Minecraft Windows edition to download the game using Xodus tool.
This Launcher is in Beta so getting error is highly common and at this point no source code available will be add later 


## Features

- Controller Support
- Mouse and Keyboard
- Online play realms and official servers
- In Game MarketPlace

## Prerequisites

Before getting started, ensure you have the following installed:

- Python3 (Most install from official python website)
- requests and pick (Python libraries)

## Installation

1. Download Launcher from release and unzip it

2. Install the requirement libraries:
   ```bash
   pip install requests
   pip install pick
   ```

3. use `xattr -dr com.apple.quarantine <Launcher Folder>` to avoid getting error
